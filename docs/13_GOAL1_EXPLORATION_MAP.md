## 0. 目标层（终点）

**目标1 = 观战：玩家部队在战役战斗中由原生战斗 AI 指挥，玩家作为观众看整场战斗，战术等价于正常敌人 AI。**

- **成功判据**：玩家不操作（或最小操作），部队由 AI Script Controller 指挥（计划链+命令落地+单位 tick），能看完整场战斗（含进攻战无黑屏）、战斗可结束/可退出。
- **已达成**：直写字段方案（RE-B3）实机可用（可看整场、无黑屏、战术与 battle_ai 等价）——**路线2 主体已通**；路线1（battle_ai 原生路径）受限未验收。
- **★不是目标的部分（附加）**：猛冲/发呆/城墙/撤退/变速/计划微调等**行为质量与可操作项** = 对 AI 的更多可操作部分，**非目标1 本身**（§5 单独列出，不参与路线判定）。
- **失败形态**：静默退出（注入禁区）/ 黑屏（天气 UI 脱节）/ 行为劣化（部队停住/猛冲无法看）。

## 1. 地图分层方法论（怎么读这张图）

| 层 | 是什么 | 回答什么问题 | 谁用 |
|---|---|---|---|
| **目标层**（§0） | 最终验收 | 我们要到哪 | 总指挥/全体 |
| **路线层**（§2） | 达成方式的逻辑分法 | 走哪条大路（互斥） | 总指挥定方向 |
| **技术路径层**（§3/§4） | 每条路线下的具体方案 | 这条路怎么走、通不通 | 前线指挥官认领 |
| **证据/行动层**（每路径内） | 已确证什么 + 下一步做什么 | 现在手里有什么、最小下一步是什么 | 执行者 |

**每条技术路径固定四段**：**原理**（为什么能通）→ **证据**（✅ 实机 / 🔶 静态 / ⬜ 无，带出处）→ **行动**（下一步最小可行实验）→ **判据**（成功/失败如何可观测判定）。

**★指挥纪律（2026-08-16 用户纠正）**：路线 = 达成方式的逻辑，**不是工作类别**。行为质量/可操作项是附加（§5），不许混进路线；否则 AI 无法专注一条路线深挖，也无法实现一个完整目标。

## 2. 路线层（两条互斥路线——达成方式的逻辑）

> 目标1 的两条路线回答同一个问题：**「让玩家部队被 AI 指挥（观战）」靠什么达成？**——靠引擎自带的 battle_ai，还是靠外部注入复刻？

### 路线1：坚守 battle_ai（假定原生 AI 完整，解决使用限制 + 验证完整程度）
- **逻辑依据**：battle_ai 值字节=1 → 引擎自行完成全链（记录→army→控制器→出生即 AI）→ **与正常敌人 AI 完全同等待遇**（11 §1/§4 机制全链确证）。若 battle_ai 的 AI 是完整的，这是最干净的路径——不用任何注入。
- **前提假设**：①battle_ai 的 AI 完整（不降智）②战役中使用限制可解（天气 UI 弹窗 / 速度锁）。
- **现状**：🟡→✅ **P0 存废决策已落（2026-08-17 野战实机）**——1-A 验收通过（完整链生效、可看整场、战斗正常结束）；**1-D 定案：战术等价无降智** → **路线1 存活**；剩余限制 = 天气 UI（进攻战，1-B）+ 部署异常（我军中位部署，军级放置差异，待根因）+ 速度锁（1-C）。
- **完成标准**：battle_ai 激活 → 进攻战观战完整（无天气 UI 弹窗/黑屏、可变速、军队不降智）。

### 路线2：外部注入复刻（认为 battle_ai 天然缺陷没救了 → 复刻 AI）
- **逻辑依据**：若 battle_ai 有天然缺陷（或限制不可解），则放弃它，用外部注入**复刻 AI 指挥状态**——直写 army/单位字段（RE-B3）已证明机制可行且战术等价。
- **前提假设**：①外部注入能完整复刻 AI（完整度问题）②注入本身可实现且可持续（注入通道问题）。
- **现状**：✅ 主体已通（直写 RE-B3 实机可用）——剩余 = 完整度验证（是否真等价）+ 注入通道完善（记录标志/判定链/可关）。
- **完成标准**：直写注入 → 观战完整，且与 battle_ai/正常敌人 AI 行为可验证等价；注入可持续（不残留/可关）。

### ★每次对话归属纪律（防混线）
- 对话开头先声明：**本轮在打通路线1（battle_ai）还是路线2（外部注入复刻）**。
- 归属判据：battle_ai 值字节/天气 UI/速度锁/降智验证 = 路线1；直写字段/注入通道/完整度复刻 = 路线2。
- 行为质量（§5 附加）不占路线——它服务于"观战体验更好"，不是目标本身，**不许当路线追**（用户 2026-08-16 纠正）。

## 7. 边界总览（墙，不可逾越）

1. **远程线程执行引擎代码 = 静默退出**（P-14 更新 10 铁证）——只有**数据写**（字段/值字节/队列 count/阈值/计划码/撤退点）是安全通道。
2. **变速锁 = 引擎设计约束**（a270=0 锁变速）——解锁需另找 tick 时间缩放字段（1-C/§5），不是改 a290 能解决。
3. **注册表恒空 = 引擎设计**——per-unit 状态机与战役战斗无关，补注册是死路。
4. **天气 UI = 战役层流程、只攻击方触发**——全军 AI 时无可靠解法；规避 = 部署后注入 / 防守战。
5. **计划码 ≠ 行为开关**（L14）——[45c]/[5ec] 是速度/权重调整；行为开关 = AI_FORCE_*_PLAN + 解除 hold。
6. **发呆只在攻城战**（L13，用户领域知识）——对照实验选攻城战。
7. **★行为质量 ≠ 目标**（2026-08-16 用户纠正）——附加项不许当路线追；路线只回答「达成观战的方式」。
8. **战斗内改一个变量一次**（§3 实机纪律）；stub 生成后必须离线反汇编验证（多次教训）。
9. **失败预算**（AGENTS §5）：同一技术路径 3 轮无新进展 → 回本图换路径。
