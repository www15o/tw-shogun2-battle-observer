# docs/ — 文档地图与阅读约定

本目录是这套工具的**方法论文档**：不讲"怎么点按钮"，讲**为什么这么写内存能生效**——
每个结论都能回到 `source`（引擎函数 RVA）或实机观测。

---

## 3. 证据等级约定

文中每个结论尽量带一档标注：

| 等级 | 含义 |
|---|---|
| **已确证** | 有**实机验证**（≥2 条独立证据，通常是"静态 + 实机"各一） |
| **推断** | 单条证据（静态反编译，或单次观测），尚未补齐第二条 |
| **未核实** | 假设 / 待验证，**不可当结论使用** |

> 本仓库历史上吃过的教训：**反编译偏移 ≠ 内存布局**。
> 多函数偏移拼接前必须先验证**对象同一性**，否则会把不同对象的字段当成一条链。

## 4. 引用规则（重要）

机制地图与探索地图里会出现三类"路径引用"，含义如下：

| 写法 | 含义 |
|---|---|
| `tools/xxx.py` | 本仓库内工具，**可直接访问** |
| `work/xxx.py` / `work/re_*_report.md` | 作者**私库工作目录**的原始路径。公开库只保留了其中可复现的子集（工具见 `tools/`，报告见 `reports/`）——**点击找不到是预期行为** |
| `docs/NN_*.md` | 若该文件不在 §2 表格中，说明它属于**未发布**的日志或目标4 文档 |

**为什么保留 `work/` 而不改写**：地图与报告是**历史记录的忠实副本**，
追改路径会破坏"结论 → 原始证据"的可回溯性。宁可让读者看到"这里原本在一个更完整的私库里"，
也不制造一个看起来能点开、实际内容对不上的链接。

## 5. 术语速查

| 术语 | 含义 |
|---|---|
| **b9** | `pending battle` 对象 `+0xb9` 字节。写 1 = 伪造"有人类参战"的分叉输入，引擎据此走人类加载链 |
| **pending battle** | 引擎里"待发生的战斗"对象；AI 之间开战时它存在但不被加载 |
| **A1** | `FUN_105caa60` 入口 hook 点——每 tick 必经，用于在写 b9 前拦截判定 |
| **CAI / FULL_MANAGER** | 战役 AI；`manager_id = 0` 即该派系全权交 CAI |
| **IsSpectator** | `env + 0x281e8`，战斗层观察者标志 |
| **PRE / POST** | 战斗加载前 / 后的阶段。规模过滤要在 PRE 阶段算，POST 已经付了加载成本 |
