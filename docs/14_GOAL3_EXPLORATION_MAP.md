## 2. 路线层（两条大路，逻辑互斥）

> 路线的区分建立在「引擎如何决定加载一场战斗」的**逻辑**上，不依赖具体地址；换地址不换路线。

### 路线1：AI 自身姿态触发加载（外部注入驱动加载机器）
- **逻辑依据**：引擎有台「战斗加载机器」（battle_mgr 创建链），入口条件 = 某参战方被识别为「人类」。AI 内战默认无人类参战方 → 机器不启动 → 自动结算。路线1 = 注入人为满足入口条件（哪怕足迹不完整），**强行把机器驱动起来**。
- **目标**：battle_mgr 创建 + 进场景。允许伴随卡死/崩（= 注入不完整的症状，逐个补）。
- **手段家族**：注入人类信息 / 其他注入引导 / 加载后拉双方 / 直接触发或完整伪造（见 §3）。

### 路线2：仿照人类存在（完整伪造「有人类参战」的数据足迹）——✅ 已闭环（2026-08-19）
- **逻辑依据**：引擎原生支持「人类与AI战斗」→ 战斗照常加载。证明引擎判「是否加载」的依据 = 「存在被识别为人类的参战方」**数据足迹**，不是操作者身份。路线2 = 完整复现足迹，让 AI 内战在引擎看来与有人类参战完全等同。
- **目标**：✅ **达成**。伪造支点定案 = **分叉输入 [pending+0xb9]=1**（1 字节）——让引擎走人类加载链，但本地玩家不参战 → setup 0x5cf168 天然旁观。
- **手段家族**（历史参考）：伪造参战方 / 伪造援军 / 伪造观察者——均被 b9 单字节方案取代为达成路径，保留作理解用。
